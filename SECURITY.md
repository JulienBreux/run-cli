# Security Policy

The Run CLI maintainers take the security of our project and its users seriously.

## Supported Versions

We provide security updates for the following versions:

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| < Latest| :x:                |

We strongly recommend always running the latest released version of Run CLI.

## Reporting a Vulnerability

If you discover a security vulnerability within Run CLI, please do **NOT** open a public issue.

Instead, please report security vulnerabilities responsibly via one of the following methods:

1. **GitHub Private Vulnerability Reporting**: Submit an advisory privately through the repository's [Security Advisories tab](https://github.com/JulienBreux/run-cli/security/advisories/new).
2. **Email**: Send an email directly to [julienbreux@google.com](mailto:julienbreux@google.com) with the subject line `[SECURITY] Run CLI Vulnerability Report`.

### Please Include:

- A detailed description of the vulnerability.
- Steps to reproduce the issue or proof-of-concept (PoC) code/commands.
- Potential impact and affected components.
- Any suggestions or mitigations you may have.

### Response Process

- We will acknowledge receipt of your vulnerability report within 48 hours.
- We will coordinate validation and development of a security patch.
- We will notify you once a fix is prepared and coordinate a public release date.
