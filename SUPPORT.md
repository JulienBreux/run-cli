# Support Guidelines

Thank you for using **Run CLI**!

This document explains where to find help, how to ask questions, and where to file issues.

## Getting Help

### Documentation & Resources
- **README**: Start by reading our [README](README.md) for quickstart and feature overviews.
- **Interactive Help**: Within the application, press `?` at any time to open the centralized interactive help modal showing all keybindings and commands.
- **Contributing Guidelines**: Review [CONTRIBUTING.md](CONTRIBUTING.md) to understand development and contribution conventions.

### Asking Questions & Discussions
For general questions, how-tos, feature suggestions, or architectural discussions:
- Start a discussion in [GitHub Discussions](https://github.com/JulienBreux/run-cli/discussions).

### Reporting Bugs
If you believe you have encountered a bug or unexpected behavior:
1. Search [existing GitHub issues](https://github.com/JulienBreux/run-cli/issues) to verify if the issue has already been reported.
2. If not, open a new [Bug Report](https://github.com/JulienBreux/run-cli/issues/new?template=bug_report.md) with reproduction steps, environment details, and logs.

### Security Inquiries
For security issues or vulnerabilities, please do not file a public issue. Refer to [SECURITY.md](SECURITY.md) for confidential reporting channels.
